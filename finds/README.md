# Daily finds

One file per day: `YYYY-MM-DD.md`

**Rules and dedup:** the authoritative process (ledger/repost rules, liveness gates, digest format) is in [`context/process.md`](../context/process.md); the dedup ledger is [`context/ledger.csv`](../context/ledger.csv). Read both before writing a digest.

## Format (keep it clean)

```markdown
# Daily Rope Access Job Digest — YYYY-MM-DD

New postings found today: N

## Country

---

- Job Title — Company — Country — https://apply-url — short notes
```

Notes examples: `English-language`, `local-language posting`, `direct match`, `above current level / stretch`.

Open the newest date in the GitHub app to skim that day’s jobs.
